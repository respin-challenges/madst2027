# MADST Challenge

**Multilingual Any-Direction Speech Translation Challenge across Nine Indian Languages**, a challenge at [ASLI 2027](https://2027.ieeeasli.org/), the 2027 IEEE International Conference on Audio, Speech, and Language Intelligence (29 November – 4 December 2027, Singapore).

**Website:** https://respin-challenges.github.io/madst2027/

## The challenge

Translate speech between any two of nine Indian languages, into text or directly into speech: Bengali, Bhojpuri, Chhattisgarhi, Hindi, Kannada, Magahi, Maithili, Marathi and Telugu. All 72 directions are evaluated.

| Task | Output |
|---|---|
| Task 1: Speech-to-text translation (S2TT) | Target-language text |
| Task 2: Speech-to-speech translation (S2ST) | Target-language speech |

| Track | Allowed |
|---|---|
| Constrained | Challenge training set and a fixed list of public checkpoints, announced at launch |
| Open | Challenge data plus any public corpora and models; proprietary APIs only if declared |

Teams can choose either track, and one task or both.

## Data

- About 20,500 original sentences, each translated by people into the other eight languages
- 81,000 newly recorded read-speech utterances from 270 speakers (30 per language, balanced by gender)
- About 16,000 training, 1,800 development and 2,700 test sentences; no sentence or speaker appears in more than one split
- Development and test sentences have human reference text and speech in every direction
