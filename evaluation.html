Evaluation

Systems are scored on all 72 directions. Each task has a constrained and an open leaderboard, ranked by a primary metric averaged over directions.

Metrics at a glance

TaskPrimary metricAlso reportedLeaderboards
Task 1: Speech-to-textchrF++BLEUConstrained, open
Task 2: Speech-to-speechASR-chrF++Predicted naturalness (MOS); human evaluation of top systemsConstrained, open

Task 1: Speech-to-text translation

System output text is compared with the human reference translation using chrF++ (primary) and BLEU, both computed with sacreBLEU. Scores are averaged over all directions, and per-direction scores are reported.

Task 2: Speech-to-speech translation

The primary metric is ASR-chrF++. System output speech is transcribed with the organisers’ ASR model for each target language, and the transcript is scored against the reference text with chrF++.

Running the same ASR on the human reference recordings gives a per-language reference point.

Predicted naturalness (MOS) is also reported. The top systems additionally receive a human evaluation.

Analysis

Results will be broken down by source language, by target language, and by whether the source sentence is an original or a translation.

Submission and scoring

Teams submit text (Task 1) or audio (Task 2) to an evaluation server, which has a daily submission limit. Each team also submits a system description. See how to submit.
