Participate

From registration to a paper at ASLI 2027, in the order you will need it.

Steps

  1. Register your team

    Registration opens on 1 February 2027.

    Registration method: to be announced.

    Register your team

  2. Get the data and baselines

    Training and development data, baseline recipes and model weights are released when the challenge opens. See data and baselines.

  3. Build your system

    Choose a task and a track. In the constrained track, use only the challenge training set and the published list of checkpoints. See tracks and the rules below.

  4. Submit outputs

    Test audio is released without references on 3 May 2027 (tentative). Submit text (Task 1) or audio (Task 2) to the evaluation server, which has a daily submission limit. Submissions close on 24 May 2027 (tentative).

    Server address, submission format and daily limit: to be announced.

    Go to the evaluation server

  5. Describe your system

    Each team submits a system description. Format, length and deadline: to be announced.

    System description template

  6. Write a challenge paper

    Challenge papers are submitted to ASLI 2027. They are limited to three pages of technical content plus one page for references, and are reviewed single-blind on a timeline separate from regular papers.

    Papers are due on 17 June 2027; notification is on 28 July 2027. Accepted papers are presented in a dedicated session in Singapore and published in IEEE Xplore as part of the ASLI 2027 Challenge & Demo Proceedings.

    Paper submission site

Rules

Tracks

  • Constrained: training uses the challenge training set only. Pretrained models are limited to the fixed list of public checkpoints announced when the challenge opens.
  • Open: the challenge data plus any public corpora, and any public model. Proprietary APIs may be used only if declared.
